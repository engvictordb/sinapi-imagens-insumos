# SINAPI — Imagens dos insumos

Fichas técnicas dos insumos SINAPI da Caixa Econômica Federal, extraídas do PDF oficial [Especificações Técnicas de Insumos SINAPI (março/2026)](https://www.caixa.gov.br/Downloads/sinapi-especificacoes-tecnicas-de-insumos/SINAPI_Fichas_Especificacao_Tecnica_Insumos.pdf).

- 5.952 imagens, ~65 MB
- 1 imagem por insumo, nomeada pelo código SINAPI: `imagens/<codigo>.jpeg`
- `mapping.json` — índice `codigo → caminho`
- `relatorio.txt` — estatísticas da extração

URLs públicas via GitHub raw:

```
https://raw.githubusercontent.com/engvictordb/sinapi-imagens-insumos/main/imagens/<codigo>.jpeg
```

Conteúdo de domínio público da Caixa. Este repositório existe como host temporário pra ingestão de imagens em outros sistemas.
